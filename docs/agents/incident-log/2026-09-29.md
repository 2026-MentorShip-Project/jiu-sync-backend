## fix-display-status-timezone / task 1.1:tasks.md 預期「⑤ naive now 修正前後皆應通過」與實際不符

- 發生了什麼:tasks.md 1.1 寫 ②③④⑤ 為邊界守護、修正前後皆應通過,但 ⑤(naive `now` → `ValueError`)在修正前為 FAIL——舊碼 `now.date()` 對 naive datetime 不會報錯,會默默回傳 `finalized_past`/`finalized_upcoming`,正是 design.md D2 要防的行為。
